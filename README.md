# aiprac

머신러닝의 기본 알고리즘을 직접 구현하고, scikit-learn·TensorFlow 구현과 비교해 본 실습 저장소입니다.
*Machine learning fundamentals implemented from scratch, then compared with scikit-learn and TensorFlow.*

## 내용

| 폴더 | 주제 |
|---|---|
| `012_LR` | 선형 회귀: 경사 하강법, 손실 함수, 학습률 |
| `013_MVLR` | 다변수 선형 회귀, 데이터셋 생성 |
| `014_Logistic Regression` | 로지스틱 회귀 직접 구현, scikit-learn·TensorFlow 버전 |
| `016_Evaluation` | 모델 평가 지표 직접 구현, scikit-learn 버전 |
| `018_BackPropagation` | 역전파 |

## 기술

Python · NumPy · scikit-learn · TensorFlow · Jupyter
